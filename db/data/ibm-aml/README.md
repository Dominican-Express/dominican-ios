# IBM AML sample

Subset of **IBM "Transactions for Anti Money Laundering (AML)"**
(Kaggle `ealtman2019/ibm-transactions-for-anti-money-laundering-aml`, v8;
github.com/IBM/AML-Data; E. Altman et al., arXiv:2306.16424), set HI-Small.

Licensed under the **Community Data License Agreement – Sharing, Version 1.0**
(`LICENSE-CDLA-Sharing-1.0.txt`), like the original data.

Changes made by Dominican Express: only a subset of rows (see `../../DATASET.md`),
plus `HI-Small-sample_rates.json`, exchange rates derived from the full set.
Built with `../../demo/aml_sample.py`.
