# Presentation

`dominican-express.pptx`: the final presentation, 18 slides, 20 minutes with a
live demo. Generated by script; speaker notes on every slide.

| Slides | Speaker | Part of the assignment |
|---|---|---|
| 1 to 4 | Jorge Pérez | Context: the product, what SurrealDB is, why a bank needs it |
| 5 to 14 | Xabier Ariznabarreta | The whole architecture: path of a request, load balancer, data model, consistency, cluster, scaling, install, the video, IBM dataset, cost of the cluster |
| 15 to 18 | Javier Pérez | Critical reflection: testing, comparison, where it fits |

The video (slide 12, `assets/video/demo.mp4`) replaces the live demo; until it
exists, slide 12 shows its outline.

## Rebuild

Requires [uv](https://docs.astral.sh/uv/) and the fonts **Geist** and
**JetBrains Mono** (both OFL; on macOS
`brew install --cask font-geist font-jetbrains-mono`). Install them also on the
computer that presents: PowerPoint does not embed them.

```sh
uv run --with python-pptx --with matplotlib --with pillow --with qrcode --with networkx python presentation/build.py
uv run --with python-pptx --with pillow python presentation/preview.py   # PNG per slide, warns if text overflows
```

| File | Does |
|---|---|
| `build.py` | The 18 slides and their speaker notes |
| `style.py` | Palette and fonts of Surrealist (flat colours), layout, boxes, arrows, tables |
| `charts.py` | Charts and terminal captures, as PNG in `assets/gen/` |
| `assets/term/*.txt` | Real terminal output used in the captures (trimmed where marked) |
| `preview.py` | Renders the deck without PowerPoint to catch overflow; the final check is opening it in PowerPoint |
