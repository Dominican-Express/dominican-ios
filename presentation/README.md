# Presentation

`dominican-express.pptx`: the final presentation, 24 slides: 20 minutes of talk and
a 10 minute demo on video. Generated by script; speaker notes on every slide.

| Slides | Speaker | Part of the assignment |
|---|---|---|
| 1 to 6 | Jorge Pérez | Context: the product, inside the app, what SurrealDB is, one engine instead of several, why a bank needs it |
| 7 to 18 | Xabier Ariznabarreta | The whole architecture: path of a request, load balancer, data model, consistency, cluster, scaling, streaming with Kafka, install, the two demo videos, IBM dataset, cost of the cluster |
| 19 to 24 | Javier Pérez | Critical reflection: testing, lessons learned, comparison, where it fits, next steps |

The demo is two videos: slide 15 (`assets/video/demo.mp4`, 4:40: live fraud response,
the cluster under failure, the Python SDK) and slide 16 (`assets/video/demo2.mp4`, 5:17:
the model, concurrency, permissions, IBM's dataset).

## Rebuild

Requires [uv](https://docs.astral.sh/uv/) and the fonts **Geist** and
**JetBrains Mono** (both OFL; on macOS
`brew install --cask font-geist font-jetbrains-mono`). The scripts look for them
in `~/Library/Fonts`, where those casks put them: without them `build.py` draws
the charts in a fallback font without warning, and `preview.py` stops with
`OSError: cannot open resource`. Also install them on the computer used for
the presentation, because PowerPoint does not embed them.

```sh
uv run --with python-pptx --with matplotlib --with pillow --with qrcode --with networkx python presentation/build.py
uv run --with python-pptx --with pillow python presentation/preview.py   # PNG per slide, warns if text overflows
```

`build.py` rewrites `dominican-express.pptx` and the charts in `assets/gen/`;
`preview.py` writes `presentation/preview/slide-NN.png` (ignored by git) and
prints `no overflow warnings` when every text fits its box.

| File | Does |
|---|---|
| `build.py` | The 24 slides and their speaker notes |
| `style.py` | Surrealist's light palette and fonts (flat colours), layout, boxes, arrows, tables |
| `charts.py` | Charts and terminal captures, as PNG in `assets/gen/` |
| `assets/term/*.txt` | Real terminal output used in the captures (trimmed where marked) |
| `preview.py` | Renders the deck without PowerPoint to catch overflow; the final check is opening it in PowerPoint |
