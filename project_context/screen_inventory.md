# Inventario de pantallas

| Pantalla de referencia | Estructura | Navegación |
|---|---|---|
| Inicio | Fondo azul noche, marca, saludo, tarjeta azul, saldo, cuatro accesos circulares, actividad reciente | Notificaciones, cuenta, enviar, Bizum, pagar, añadir dinero, actividad |
| Tarjetas | Carrusel, principal, saldo disponible, bloqueo/datos, límite de gasto, gestión | Selección de tarjeta, verificación demo, gestión y límites |
| Movimientos | Búsqueda, tres filtros, mes, seis movimientos | Detalle y exportación demo |
| Transferir | Contactos/cuenta bancaria, favoritos, importe, concepto, continuar | Revisión y resultado simulado |
| Bizum | Enviar/solicitar, ocho contactos, importe, destinatario | Contactos, revisión y resultado simulado |
| Cuenta compartida | Resumen, saldo, avatares, titulares y permisos, invitar | Detalle de titular, invitación demo |
| Insights | Selector temporal, anillo, cuatro categorías, alerta de ocio | Cambio de período y detalle de categoría |
| Perfil | Avatar Ana García, cinco filas | Datos personales, notificaciones, límites, domiciliaciones, documentos, seguridad |

Las vistas auxiliares mantienen el lenguaje de la referencia; no existe referencia visual para ellas. Acceso a Cuenta compartida e Insights desde Inicio, después de la actividad; en iPhone pequeño se desplaza verticalmente.
